Protocol and provenance

Visual observation

The model receives first-person PNG observations and action feedback. It receives no map, coordinates, or reference route. Actions are left, right, and forward; square turns are 90°, hexagon/triangle turns are 60°.

Image context

The current action batch is supplied in order. On transport limits, remove the earliest image round while retaining the latest current view. Public text feedback remains. Native harnesses and the public-text API baseline manage conversation state differently.

Interpretation

Different sources, prompts, defaults, and state-management policies can affect behavior. Compare matched maps and budgets. Successful-run summaries are conditional on success; inspect unfinished cases and their coverage too.
